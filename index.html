Simple Twitch Chat

A Twitch chat overlay for OBS with 7TV, BTTV and FFZ emotes, 7TV paints and badges. Pick your options, copy the URL, and paste it into an OBS browser source. Nothing to install, no login needed. Source and docs on GitHub.

Add it to OBS

  1. In OBS, add a source: + → Browser.
  2. Make sure Local file is unticked, and paste the URL into URL.
  3. Set width and height, e.g. 450 × 900. The background is transparent.
  4. Replace everything in Custom CSS with the CSS from Look below: the recommended CSS, or your theme's CSS.
  5. Click OK. To change options later, edit the URL in the source's properties.
